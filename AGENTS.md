# Documentação do projeto

Ao concluir uma alteração relevante nas telas, dados, fluxos ou arquitetura da Octacore, atualize `DOCUMENTACAO.md` no mesmo trabalho. Mantenha o estado atual, as limitações e os próximos passos corretos; acrescente uma entrada datada no histórico com a verificação realizada. Diferencie sempre interface pronta, simulação no navegador e integração real com backend. Para alterações pequenas sem impacto nesses pontos, não é necessário acrescentar uma entrada.
